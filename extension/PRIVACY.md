# lata link privacy policy

lata link collects nothing.

- It has no account, no analytics and no background script.
- It makes no network requests and stores nothing in the browser.
- It runs only on Steam Workshop item pages (`steamcommunity.com/sharedfiles/filedetails/*` and
  `steamcommunity.com/workshop/filedetails/*`), where it reads the item's id from the page address
  and adds one button.
- The button is a plain link (`lata://install-mod?id=<id>` or
  `lata://install-collection?id=<id>`). Clicking it hands that id to the lata launcher app on your
  own computer, and to nobody else.

Questions: https://github.com/valentin-marquez/lata/issues
