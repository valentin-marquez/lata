# Store listing

What the Firefox and Chrome listings say.

## Name

lata link for Project Zomboid (Spanish: lata link para Project Zomboid)

## Summary

Install Project Zomboid mods and collections from the Steam Workshop into lata launcher.

Instala mods y colecciones de Project Zomboid desde el Workshop de Steam en lata launcher.

## Description

Install Project Zomboid mods and collections from the Steam Workshop straight into lata launcher.

One button under Subscribe. Click it, pick an instance, done.

- Only on Project Zomboid mods and collections
- Speaks the language of the Steam page
- lata always asks before installing
- Collects nothing

Needs lata launcher: https://github.com/valentin-marquez/lata

Not affiliated with Valve or The Indie Stone.

## Permissions

Runs only on steamcommunity.com Workshop item pages, to add the button.
